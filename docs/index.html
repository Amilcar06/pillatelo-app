Pillatelo: Finanzas y Gastos

Política de Privacidad y Tratamiento de Datos

🛡️

Tus finanzas son estrictamente tuyas

Pillatelo fue concebida con privacidad total por diseño. No tenemos servidores centrales, no rastreamos tus transacciones ni vendemos datos a terceros. Toda tu información reside únicamente en tu dispositivo.

01. Información que NO Recopilamos

A diferencia de otras aplicaciones financieras:

  • No recopilamos datos personales: No solicitamos tu nombre real, número de documento, correo electrónico ni número de teléfono.
  • No requerimos vinculación bancaria en la nube: No nos conectamos a tus credenciales bancarias ni APIs de bancos.
  • No almacenamos datos en servidores remotos: No existe una base de datos central en la nube donde se guarden tus ingresos, gastos, deudas o préstamos.
  • Sin identificadores de publicidad: No usamos el Google Advertising ID ni SDKs de rastreo comercial (como Google Analytics, AppsFlyer o Facebook SDK).

02. Almacenamiento Local (SQLite)

Todos los registros creados por el usuario (cuentas, movimientos, categorías, presupuestos, préstamos, metas de ahorro y configuración de seguridad) se almacenan de manera local en el almacenamiento aislado (sandbox) del sistema operativo Android utilizando el motor de base de datos SQLite.

El acceso a este espacio está restringido exclusivamente a la aplicación por los mecanismos de seguridad propios del sistema operativo.

03. Protección mediante Código de Acceso (PIN)

Pillatelo permite configurar un código PIN de 4 dígitos para proteger el ingreso a la aplicación. Dicho PIN se procesa de forma hash y se guarda de forma segura y local en tu dispositivo, garantizando que nadie sin tu autorización física pueda ingresar a consultar tu información.

04. Permisos Requeridos por el Sistema

Pillatelo solicita el mínimo estricto de permisos para operar:

  • Notificaciones (POST_NOTIFICATIONS): Utilizado únicamente para emitir recordatorios locales en tu dispositivo (por ejemplo, pagos pendientes de préstamos o fechas límite de metas). No se envían notificaciones push desde servidores remotos.
  • Almacenamiento / Compartir archivos: Requerido temporalmente cuando solicitas exportar tus reportes en formato PDF o CSV a través del menú de la aplicación, para enviarlo o guardarlo en la aplicación de tu preferencia.

05. Control y Eliminación Permanente de Datos

El usuario es el único propietario de sus registros. En cualquier momento puedes:

  • Eliminar registros, cuentas o movimientos específicos desde la interfaz.
  • Borrar la totalidad de los datos desde la opción Ajustes > Aplicaciones > Pillatelo > Borrar datos de tu teléfono.
  • Desinstalar la aplicación: esto elimina automáticamente la base de datos local y todos los registros asociados de forma irrevocable.

06. Cumplimiento con Google Play y Legislación

Esta política cumple íntegramente con los requisitos de la sección Seguridad de los Datos (Data Safety) de Google Play Console. Declaramos que:

  • La aplicación no comparte ningún dato con terceros.
  • La aplicación no recopila datos para transmisión remota.
  • Todo el procesamiento de datos se realiza en el dispositivo.
